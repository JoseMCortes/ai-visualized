LangChain Utils, Live

LangChain isn't an algorithm to reimplement — it's a set of utilities for gluing prompts, models, and parsers together. So this page runs the real library: a prompt template, a model call, and a structured output parser, composed with LCEL's .pipe() and actually executed, using your own API key.

This makes a real API call straight from your browser to OpenAI or Anthropic, using a key you paste in below. It's stored only in this browser (localStorage) and sent only to the provider you choose — never to any server we operate — but it will use your account's quota and may incur a small real cost. Calling a provider directly from client-side code like this needs an explicit opt-in (dangerouslyAllowBrowser) for exactly that reason: a real product should proxy these calls through a server so the key never reaches a browser at all. This page is for seeing the mechanism work, not a template for production.

How to read this

  1. The template runs immediately, with no key — it's pure string substitution. ChatPromptTemplate.fromMessages([...]) fills your review text and the parser's "answer in this shape" instructions into a system + human message pair.
  2. The model is the one line that changes between providers — ChatOpenAI or ChatAnthropic — everything upstream and downstream of it is identical either way. That's the actual value LangChain adds: write the chain once, swap the model underneath it.
  3. The parser is built from the same zod schema twice: once to generate the formatting instructions the model is told to follow, and once to validate and parse whatever text comes back into a real typed object.
  4. The chain — prompt.pipe(model).pipe(outputParser) — is LCEL: three independent pieces composed with .pipe() into one runnable. The demo calls the three pieces one at a time instead of through the composed chain, purely so every intermediate value stays visible — the request that reaches the provider is identical either way.

Self-Attention, Visualized

A 0.8M-parameter GPT, trained on Shakespeare and re-implemented from scratch to run in your browser. Type a phrase and see which earlier characters each position attends to — the mechanism at the heart of every transformer.

How to read this

  1. Every character becomes a vector. Through self-attention, each position builds its next-step representation by pulling in information from earlier positions.
  2. The arc diagram shows one query character (highlighted) and the arcs to the earlier characters it draws from. Thicker, brighter arc = more attention weight.
  3. The heatmap is the whole matrix: row = query character, column = key character, brightness = weight. It is triangular because a position can only look backwards.
  4. Layer and Head pick which of the model's 4 × 4 attention patterns you are looking at. Different heads specialise — some track the previous character, some jump to punctuation or the start of a word.

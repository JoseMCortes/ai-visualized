Word Embeddings, Visualized

An embedding turns a word into a list of numbers — a point in space — so that words with related meaning land near each other and consistent relationships become consistent directions. Below: a hand-built toy to build intuition, then ~250 real GloVe vectors.

How to read this

  1. Every word is a vector — here 50 numbers from GloVe, trained so that words appearing in similar contexts get similar vectors.
  2. Nearby = similar. Hover a word to see its closest neighbours by cosine similarity (the angle between the two vectors).
  3. Directions carry meaning. The analogy tool computes a − b + d and lands you near a real word: king − man + woman ≈ queen, paris − france + germany ≈ berlin.
  4. 50 dimensions can't be drawn, so the map is a 2-D projection — PCA (keeps the biggest spread) or t-SNE (keeps neighbourhoods). Both lose information; switch between them to see what changes.

Softmax with Temperature

Softmax turns a list of raw scores into a probability distribution. The temperature T is a single dial that controls how sharp or flat that distribution is — drag it and watch every number update live, top to bottom.

This computes real softmax from scratch — no model, no API. The "real embeddings" preset reuses genuine GloVe vectors from this portfolio's Word Embeddings demo; the rest are hand-picked scores chosen to make a specific pattern (a clear winner, a close call, several plausible options) easy to see.

How to read this

  1. The formula. For each score x: probability = e^(x / T) / Σ e^(x / T). Dividing by T first stretches or shrinks the gaps between scores; exponentiating then turns bigger gaps into disproportionately bigger probabilities.
  2. T = 1 is plain softmax — no stretching. That's the natural starting point (the Reset button returns here).
  3. T < 1 sharpens. Dividing by a small number stretches the gaps between scores, so the exponential exaggerates the leader. As T → 0, the winner takes essentially all the probability — softmax becomes "always pick the top score".
  4. T > 1 softens. Dividing by a large number shrinks every score toward 0, so e^0 = 1 for all of them — the distribution flattens toward uniform, and the original ranking matters less and less.
  5. Entropy is the single number for "how spread out is this distribution" — 0 means one option has all the probability, ln(N) means all N options are equally likely. Watch it slide as you move T.
  6. The chart plots every entry's probability across the full temperature range at once. The ranking never changes — softmax can't reorder entries, so lines never cross — but watch how fast the gaps between lines open and close: near T = 0.05 they fan out to 0% or 100%, and above T ≈ 10 they all collapse toward the same flat line.
